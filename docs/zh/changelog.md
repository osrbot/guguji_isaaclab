# 中文更新日志摘要

这里汇总近期最重要的改动，完整历史请查看仓库根目录的 `CHANGELOG.md`。

## v0.9.0 · 2026-05-06

### 奖励函数强化 — sim-to-real 鲁棒性

对标 agibot_x1_train 和 unitree_rl_lab，补齐六处设计缺口：

- **速度跟踪改为 yaw frame** — body-frame 前向速度随机器人倾斜而偏转；yaw frame 消除 roll/pitch 影响，信号始终水平。
- `joint_pos_limits` 权重 **-0.05 → -2.0** — 原权重比同类项目低 40 倍，关节频繁撞限位会损坏实机执行器。
- `action_rate` 权重 **-0.004 → -0.03** — 减少关节抖动，降低电机发热。
- 新增 `lin_vel_z` **（-1.5）** — 惩罚垂直弹跳；三个参考项目均有此项。
- 新增 `ang_vel_xy` **（-0.1）** — 惩罚翻滚/俯仰角速度；原设计只惩罚偏航。
- 新增 `feet_slide` **（-0.1）** — 惩罚接触时脚的水平速度，防止策略学会拖脚。

## v0.7.0 · 2026-04-24

### PPO 训练发散问题修复

定位并修复了五个导致训练不稳定的根本原因：

- `init_std` 1.0 → **0.1** — 旧值导致每步 ±0.08 rad 噪声，episode 极短，std 在训练中涨到 12+
- `num_steps_per_env` 24 → **2048** — 24 步（0.48s）短于一个步态周期（0.72s），GAE 看不到完整步态
- `max_iterations` 500 → **30000**（平地），1500 → **5000**（粗糙地形）— 双足训练所需迭代数远超模板默认值
- `clip_actions` None → **10.0** — 无裁剪时大 std 输出极端关节目标，直接打翻机器人
- `num_mini_batches` 4 → **32** — 与更大的 rollout buffer 匹配
- `reset_robot_joints position_range` (0.85, 1.15) → **(1.0, 1.0)** — 缩放扰动对近零关节无意义，早期训练增加不必要难度
- `RayCasterCfg`：`attach_yaw_only=True` → `ray_alignment="yaw"`（API 更新）

## v0.5.0 · 2026-04-19

### 步态质量优化

这一版重点解决两个问题：

- 机器人步子太碎
- 摆动相抬膝不够明显

主要调整包括：

- 增大髋关节摆幅
- 增大膝关节摆幅
- 增强摆动相抬膝缩放
- 缩短支撑相比例
- 扩大策略残差预算

同时还提高了交替迈步和抬膝相关奖励目标，并让离地奖励更容易触发。

## v0.4.0 · 2026-04-18

### 稳定性与对称性修复

这一版修复了：

- 训练时标准差配置导致的崩溃
- 左右腿不对称导致的跛行
- 交替步态激励不足

核心更新包括：

- 改用 `distribution_cfg` 和 `std_type="log"`
- 提高 `hip_alternation` 与 `knee_flexion`
- 新增膝关节对称惩罚
- 提高 `feet_air_time` 奖励
