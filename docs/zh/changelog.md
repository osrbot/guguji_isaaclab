# 中文更新日志摘要

这里汇总近期最重要的改动，完整历史请查看仓库根目录的 `CHANGELOG.md`。

## 0.5.0 · 2026-04-19

### 步态质量优化

这一版重点解决两个问题：

- 机器人步子太碎
- 摆动相抬膝不够明显

主要调整包括：

- 增大髋关节摆幅
- 增大膝关节摆幅
- 增强摆动相抬膝缩放
- 缩短支撑相比例
- 扩大策略残差预算

同时还提高了交替迈步和抬膝相关奖励目标，并让离地奖励更容易触发。

## 0.4.0 · 2026-04-18

### 稳定性与对称性修复

这一版修复了：

- 训练时标准差配置导致的崩溃
- 左右腿不对称导致的跛行
- 交替步态激励不足

核心更新包括：

- 改用 `distribution_cfg` 和 `std_type="log"`
- 提高 `hip_alternation` 与 `knee_flexion`
- 新增膝关节对称惩罚
- 提高 `feet_air_time` 奖励

## 0.3.0 · 2026-04-18

### `play.py` 兼容性与防绕圈更新

这一版处理了：

- `rsl_rl >= 5.0` 下 `play.py` 的兼容问题
- TorchScript / ONNX 导出方式更新
- 观测接口变更
- 缺少偏航惩罚导致的绕圈行为

同时还：

- 降低了课程起始速度
- 提高了课程最高速度
- 增加了训练迭代数
- 加入了小幅 entropy bonus
